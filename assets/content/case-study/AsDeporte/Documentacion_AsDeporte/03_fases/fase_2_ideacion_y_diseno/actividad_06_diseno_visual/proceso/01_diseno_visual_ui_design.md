Diseño Visual (UI Design):

Sexto Paso de la Fase 2: Diseño Visual (UI Design)

1.  Propósito: Aplicar la estética visual a los wireframes y especificaciones de
interacción para crear el aspecto final de la nueva plataforma digital B2C.
Definir la paleta de colores, tipografía, estilo de iconografía, imágenes y otros
elementos visuales que reflejen la identidad de marca de AsDeporte y creen
una experiencia atractiva y coherente.

2.  Objetivo para AsDeporte: Desarrollar mockups de alta fidelidad para las

pantallas clave del MVP B2C que sean visualmente atractivos, alineados con la
marca AsDeporte (energía, profesionalismo, comunidad), y que refuercen la
usabilidad definida en etapas anteriores. Asegurar una apariencia consistente
entre la web responsive y la aplicación móvil nativa, integrando visualmente
Asdeporte Plus y la función "Tribu".

3.  Revisión de Entregables Anteriores Relevantes para UI Design:

○  Acción: Revisa los entregables que servirán de base para aplicar el diseño

visual. Esto incluye:

■  Los Wireframes de Alta Fidelidad (para ver el layout y la jerarquía

de los elementos en cada pantalla).

■  Las Especificaciones de Diseño de Interacción (para entender

cómo se comportan los elementos y aplicar estilos a sus diferentes
estados - normal, hover, activo, deshabilitado, error, etc.).

■  La Identidad de Marca de AsDeporte (guias de marca existentes si

las hay, logos, colores, tipografía actual - de los documentos y
entrevistas con Marketing/Ventas).

■  Los Hallazgos de la Investigación de Usuarios B2C (especialmente
sobre la percepción de la plataforma actual en términos visuales o de
sensación, y las expectativas de una experiencia "premium" para
miembros Plus).

■  Las Ideas de Solución de la fase de Ideación relacionadas con la

estética o la sensación de la interfaz.

■  El Análisis Competitivo Digital (para ver las tendencias visuales en

el mercado y oportunidades de diferenciación estética).

■  Los Problem Statements relevantes (para recordar que el diseño
visual debe apoyar la solución de problemas de usabilidad y no
empeorarlos).

○  Foco: Tener una comprensión clara de la estructura, funcionalidad e

interacción, así como la identidad visual deseada y cómo aplicarla para crear
una interfaz atractiva y utilizable.

4.  Definición de la Dirección Estilística Visual:

○  Acción: Antes de diseñar pantallas individuales, define los elementos

visuales clave que compondrán la interfaz.

○  Foco:

■  Paleta de Colores: Define los colores primarios (alineados con la
marca AsDeporte), colores secundarios (para acciones, feedback,
estados), colores neutros y colores de acento. Considera la
accesibilidad (contraste) desde el principio. [Ref: Color en "Guía
Exhaustiva de Diseño de Producto Digital.pdf" (pág 12)].

■  Tipografía: Selecciona las fuentes tipográficas para encabezados,
cuerpo de texto, botones, etc. Considera la legibilidad en diferentes
tamaños y dispositivos. [Ref: Tipografía en "Guía Exhaustiva de
Diseño de Producto Digital.pdf" (pág 13)].

■  Estilo de Iconografía: Define si los iconos serán lineales, rellenos,

con contorno, su estilo visual general. Asegúrate de que sean claros y
comprensibles.

■  Estilo de Imágenes e Ilustraciones: Define el tipo de imágenes
(fotografía deportiva, ilustraciones) y su estilo para que sean
coherentes con la marca.

■  Estilo de Elementos de Interfaz (UI Kit Básico): Define la

apariencia de los elementos interactivos comunes (botones, campos
de formulario, checkboxes, radio buttons, toggles, sliders) y
elementos de presentación (tarjetas de evento, listas, tablas).

○  Herramientas: Software de diseño UX/UI (Figma, Sketch, Adobe XD),

creación de Mood Boards (digitales o físicos) para explorar estilos visuales,
guías de estilo de marca existentes.

5.  Creación de Mockups de Alta Fidelidad (Pantallas Clave del MVP B2C):

○  Acción: Aplica la dirección estilística visual definida a los wireframes de alta
fidelidad para crear los mockups (representaciones visuales estáticas) de las
pantallas clave del MVP B2C.

○  Foco: Mostrar la apariencia final de cada pantalla, incluyendo colores,

tipografía, imágenes, iconos y estilos de elementos interactivos. Asegúrate
de que el diseño visual sea coherente con los wireframes (layout y jerarquía)
y las especificaciones de interacción (estados de elementos). Diseña las
pantallas para la experiencia principal (ej. móvil) y luego adáptalas para la
experiencia web responsive. Presta especial atención a las pantallas de los
flujos críticos y las funcionalidades clave (búsqueda/listado de eventos,
página de detalle de evento, formulario de inscripción, perfil, Tribu, Plus).
Integra visualmente los elementos de Asdeporte Plus (ej. indicadores de
miembro Plus, estilos específicos de secciones Plus) y la función "Tribu"
(estilo de publicaciones, perfiles de usuario en la comunidad).

○  Herramientas: Software de diseño UX/UI (Figma, Sketch, Adobe XD).
6.  Diseño Visual Adaptado a Diferentes Contextos (Web Responsive y App

Nativa):

○  Acción: Asegúrate de que el diseño visual funcione y sea coherente en la
plataforma web responsive y la aplicación móvil nativa (iOS y Android),
considerando las convenciones de cada plataforma.

○  Foco: Adaptar el layout, los tamaños de los elementos, la tipografía y los
patrones de navegación visuales para que se vean y funcionen bien en
diferentes tamaños de pantalla (escritorio, tablet, móvil) y sistemas operativos
móviles (iOS, Android - si hay diferencias visuales nativas significativas a
considerar). Mantener una identidad visual coherente de AsDeporte en todas
las plataformas.

○  Herramientas: Software de diseño con capacidades responsive y de diseño

para iOS/Android.

7.  Refinamiento Visual y Creación de un UI Kit Inicial:

○  Acción: Refina los mockups visuales y comienza a organizar los elementos

de interfaz reutilizables en un UI Kit básico.

○  Foco: Asegurar la consistencia visual en todas las pantallas. Crear un

conjunto de componentes UI (botones, campos de formulario, tarjetas de
evento, encabezados, etc.) con sus diferentes estados, definidos con los
estilos visuales. Esto sentará las bases para un futuro Design System y
facilitará la consistencia y el handoff a desarrollo.

○  Herramientas: Software de diseño (funcionalidades de componentes,

estilos), creación de un UI Kit/Librería en el software de diseño.

8.  Validación Interna del Diseño Visual:

○  Acción: Presentar los mockups de alta fidelidad y la dirección visual al

equipo del proyecto (stakeholders clave: Liderazgo, Producto,
Marketing/Ventas, Diseño, Tecnología) para obtener feedback sobre la
estética, la alineación con la marca y cómo se percibe la experiencia visual.

○  Foco: Validar si el diseño visual es atractivo, refleja la identidad de marca

AsDeporte, y si apoya (o al menos no perjudica) la usabilidad y la interacción
definidas en etapas anteriores. Asegurar la alineación visual con
Marketing/Ventas.

9.  Iteración Basada en Feedback:

○  Acción: Refinar los mockups y los elementos del UI Kit basándote en el

feedback recibido.

○  Foco: Asegurarte de que el diseño visual final para el MVP B2C sea

atractivo, coherente con la marca y usable.

Entregables del Paso de Diseño Visual (UI Design):

1.  Mockups de Alta Fidelidad: Representaciones visuales completas de las pantallas

clave del MVP B2C para la aplicación móvil y la web responsive.

2.  UI Kit Inicial: Un conjunto de componentes de interfaz de usuario reutilizables con

sus estilos visuales definidos.

3.  Especificaciones de Estilo Visual: Documentación de la paleta de colores,

tipografía, estilos de iconografía, etc. (Puede integrarse con el UI Kit).

Al completar este paso, habrás definido la apariencia final de la nueva plataforma digital
B2C, lista para ser documentada en detalle para el desarrollo y para crear prototipos de alta
fidelidad interactivos para pruebas finales con usuarios.
